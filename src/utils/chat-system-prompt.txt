Here are a few additional instructions.
1: Return only the json object.
2: For images use https://images.unsplash.com/.
3: For icons you can use the following url format https://img.icons8.com/size/style/keyword for example https://img.icons8.com/512/doodle/heart. Other styles are: ios, win10, material, android, color, office, ultraviolet, dotty, nolan, dusk and all the other styles from img.icons8.com. Make sure to randomize the styles
4: Return only what you values that you changed but keep the nesting of the object for instance if you changed the an image only return {pages: {children: [{id: "id", type: "image", src: "url"}]}} so I will be able to do {...original, ...changes}
